A handoff gives one phone number to an agent and pauses the bot for that number. Other conversations on the same WhatsApp account keep the bot.

## When it happens

Assigning the thread to an agent from the inbox transfers that phone number and pauses the bot. The thread then shows a handoff banner so the next person sees that the bot has stopped.

New conversations can still be assigned round-robin across the agents who are on. A handoff is specific to the number that was transferred. It is not a change to the round-robin list.

## The Handoffs tab

**Automation → Handoffs** lists transfers and sessions for the selected account. From that list a manager can see who is waiting on a person.

Resume the bot for that number when the agent is done. The next inbound message is handled by keywords, flows, and AI again. Cancelling a session drops the in-progress flow for that chat.

## What the agent does

The agent replies in **Conversations** like any other thread. The [24-hour window](../conversations/service-window.md) still applies. Internal notes stay the right place for context the customer should not see.
