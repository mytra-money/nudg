Start here when a page, a webhook, or an install does not do what the rest of this guide describes.

[Common issues](common-issues.md) covers the cases that show up on a new bench: the wrong Frappe version, a missing app, the wrong URL, a busy dev-server port, permissions, and a webhook pointed at `/nudg`.

For a first-time setup that has not failed yet, use [Your first steps](../setup-guide/your-first-steps.md).
