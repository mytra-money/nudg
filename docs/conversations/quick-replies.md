A quick reply is a saved answer with a shortcut. The team uses it so the same greeting or tracking update is one pick, not a retype.

## Create one

Open **Settings → Quick Replies** and add:

| Field | Example |
| --- | --- |
| Title | Welcome |
| Shortcut | `greet` |
| Body | The message the customer will receive |
| Account | The number this reply belongs to, when you have more than one |

Shortcuts are typed without the leading slash. `/greet` in the composer looks up the shortcut `greet`.

## Use one

In an open thread, type `/`. A picker lists the replies for that account. Choose one, or keep typing the shortcut. The body is inserted into the composer. You can edit it before you send. Sending still follows the [24-hour window](service-window.md): a quick reply is a normal message, so the window has to be open.

## Where they live

Quick replies are Nudg records (WA Quick Reply). They are not WhatsApp templates and they are not submitted to Meta. Use a template when you need to message someone whose window is closed, or when you are sending a campaign.
