People who work in Nudg are Frappe users with a WhatsApp role. They sign in on the site and open `/nudg`. They do not need the Desk icon for ordinary replies.

## Roles

| Role | Can |
| --- | --- |
| WhatsApp User | Open Conversations, reply, use quick replies, add internal notes, read Analytics for their accounts |
| WhatsApp Manager | Everything a user can do, plus connect a number, campaigns, catalogs, the chatbot, and Integrations |
| System Manager | Desk, the access token, the webhook secret, and site-wide WhatsApp settings |

Install creates the two WhatsApp roles. A System Manager assigns them. **Settings → Team & Agents** is the place to add a teammate, pick WhatsApp User or WhatsApp Manager, and turn the user on or off.

An owner account is the primary manager. Do not remove that user to "clean up" the list.

## What each person should open

| Person | Start here |
| --- | --- |
| Agent | Conversations |
| Person running a broadcast | Marketing |
| Person connecting Meta | Integrations |
| Person fixing a rejected webhook | Integrations → Logs, then Settings → WABA Profile if they are System Manager |

Marketing, Catalogs, Automation, and Integrations are hidden from users who are not managers. If a user is sent back to Conversations when they open one of those pages, they need WhatsApp Manager.
